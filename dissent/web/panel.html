panel triage

One lookup saves a reader fifteen minutes of tab-switching. A panel changes which variants get read at all. Paste a list and every one is interpreted against the same six sources, then ordered by what a person still has to decide.

Or load a panel

Ordered by tier, then by how much there is to read inside it.

How the order is decided

No score. A single number would invite you to trust a precision that is not here. Each tier is computed from structured fields only — ClinVar's own labels, their review status and dates, and this tool's computed call — never from the wording of a conflict message. The rule is below so you can disagree with it.

What this is not. It is not a clinical priority list. It says nothing about which variant matters most to a patient, which is a question about the phenotype in front of you and cannot be answered from a database. It ranks one thing: how much the public record disagrees with itself, and therefore how much of it a person still has to read.
